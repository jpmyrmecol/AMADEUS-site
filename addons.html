Installation

On the AMADEUS Home screen, open Add-ons and drop an add-on ZIP into the installer or select it with Browse.

For developers

Use the official template and developer guide.

To request a listing, open a GitHub issue with a public repository, installable ZIP, license, supported OS, and tested AMADEUS version.

Feature requests

Suggest new features and improvements in Feature Requests discussion. Describe the proposed feature and its intended use.

Security

Add-ons are not sandboxed. They run with your file and network permissions. Install only from trusted developers. A listing does not guarantee safety or scientific validity.
